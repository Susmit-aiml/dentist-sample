# 🦷 DentEase Dental Clinic — Modern Web Platform

A premium, modern dental clinic web application designed for high patient trust, effortless appointment booking, and clinical transparency.

---

## ✨ Features

- **Interactive Before & After Case Studies**: Interactive comparative sliders showcasing verified smile transformations (veneers, laser whitening, clear aligners, and dental implants).
- **Clinical Treatment Writeups**: Deep-dive case study blogs documenting diagnosis, procedure, recovery, and specialist insights.
- **Smart Appointment Booking**: Multi-step booking wizard with real-time slot selection and doctor consultation fee deposit integration.
- **Doctor & Staff Admin Portal**: Secure PIN-protected dashboard (`Ctrl + Shift + A`) to manage patient appointments, update consultation fees, and publish new case studies.
- **AI Dental Assistant**: Interactive automated chatbot answering common dental queries, procedure guidance, and clinic FAQs.
- **Localised for India**: Built with Indian currency (₹), authentic clinical imagery, clinic timings, and direct WhatsApp integration.

---

## 🛠️ Tech Stack

- **Core**: Vanilla HTML5, Modern ES6+ JavaScript
- **Styling**: Custom Vanilla CSS Design System with responsive layouts and micro-animations
- **Tooling & Bundler**: [Vite](https://vitejs.dev/)

---

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Build for Production
```bash
npm run build
```
The optimized production bundle is generated in the `dist/` directory.

### 4. Preview Production Build
```bash
npm run preview
```

---

## 🔒 Staff / Admin Portal Access

- Access via the **Doctor / Staff Portal** link in the header/footer or press `Ctrl + Shift + A`.
- Default Access PIN: `1234` (configurable inside portal settings).
